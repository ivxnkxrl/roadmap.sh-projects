# Personal Portfolio
A responsive personal portfolio website built using HTML and CSS.
This project builds upon the [Basic HTML Website](../basic-html-website/) project
by adding styling, responsive layouts, and an improved user interface.

## Features
- Semantic HTML: Meaningful HTML elements for structured content.
- Multiple Pages: Home, Projects, Articles, and Contact.
- Responsive Design: Layouts that adapt to different screen sizes.
- Consistent Styling: Cohesive color scheme and typography.
- CSS Layouts: Flexbox, media queries, and the CSS box model.
- Styled Contact Form: Name, email, and message fields.
- SEO Meta Tags: Relevant metadata for each page.

## Technologies Used
- HTML5
- CSS3

## Learning Objectives
- Practice styling websites using CSS.
- Create responsive layouts for mobile and desktop.
- Understand Flexbox, media queries, and the box model.
- Apply consistent typography, colors, and spacing.
- Improve navigation and form styling.
