# Basic HTML Website

A simple multi-page website built with **HTML** to practice semantic page structure, navigation, basic search engine optimization (SEO), and HTML forms.

This project is based on the [Basic HTML Website project](https://roadmap.sh/projects/basic-html-website) from roadmap.sh.

## Features

- **Semantic HTML:** Uses meaningful elements such as `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>` to organize content.
- **Multiple pages:** Includes pages connected by a consistent navigation bar.
- **SEO meta tags:** Each page includes a descriptive `<title>` and relevant meta tags in its `<head>`, such as `description` and `viewport`.
- **Contact form:** Provides fields for a visitor's name, email address, and message, with appropriate labels and basic HTML validation.

## Pages

- **Home:** Introduces the website.
- **Projects:** Displays projects or work samples.
- **Articles:** Contains articles or written content.
- **Contact:** Includes a form for visitors to send a message.

## Technologies Used

- HTML5

## Getting Started

1. Clone the repository or download the project files.
2. Open `index.html` in a web browser.
3. Use the navigation bar to explore the pages.

> **Note:** The contact form is a frontend-only example. Submitting messages requires a backend or a form-handling service; HTML alone does not deliver messages.

## Learning Objectives

- Write accessible, semantically structured HTML pages.
- Connect multiple pages with relative links and consistent navigation.
- Add useful SEO metadata to each page.
- Build a labeled contact form using standard HTML input elements.
