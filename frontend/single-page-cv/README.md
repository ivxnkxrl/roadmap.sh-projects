# Single-Page-HTML-CV

A simple single-page CV built using HTML, featuring semantic HTML structure, SEO meta tags, and Open Graph (OG) tags.

## How to Run

1. Clone the repository:
  git@github.com:ivxnkxrl/roadmap.sh-projects.git

2. Navigate to the project folder:
  cd frontend/single-page-cv

3. Open `index.html` in your web browser.

## Technologies Used

- HTML5
- SEO Meta Tags
- Open Graph (OG) Tags
