# Testimonial Cards
A collection of testimonial cards built using HTML and CSS to practice CSS positioning, layouts, and styling.
The cards present feedback from users or customers in different visual formats.

This project is based on the Testimonial Cards challenge from [roadmap.sh.](https://roadmap.sh/projects/testimonial-cards)

## Features
- Multiple Testimonial Cards: Displays testimonials in different card layouts.
- User Information: Includes names, roles, and profile images where applicable.
- CSS Layouts: Uses layout and positioning techniques to organize card content.
- Visual Styling: Applies spacing, borders, typography, and other CSS styles.

## Technologies Used
- HTML5
- CSS3

## Learning Objectives
- Practice structuring testimonial components with HTML.
- Improve CSS positioning and layout skills.
- Explore different card designs and content arrangements.
- Build reusable, visually consistent UI components.
