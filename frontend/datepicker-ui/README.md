# Datepicker UI
A simple and responsive datepicker interface built using **HTML and CSS**.
This project focuses on practicing CSS layouts, positioning, and styling by recreating a calendar interface.

This project is based on the [Datepicker UI](https://roadmap.sh/projects/datepicker-ui) challenge from roadmap.sh.

## Features
- **Date Input:** A date input field with a calendar icon.
- **Calendar Layout:** Displays a monthly calendar with days of the week and dates.
- **Month Navigation:** Includes previous and next month navigation arrows.
- **Clean Design:** Simple and organized calendar interface.
- **Static Interface:** Focuses on visual design without JavaScript functionality.

## Technologies Used
- HTML5
- CSS3

## Learning Objectives
- Practice structuring a datepicker interface using semantic HTML.
- Improve CSS layout skills using Flexbox and Grid.
- Learn how to position and align calendar elements.
- Practice styling form elements, buttons, and icons.
- Build a clean and visually consistent user interface.
