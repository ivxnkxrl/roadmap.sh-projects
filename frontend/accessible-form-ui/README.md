# Accessible Form UI
A simple and accessible form interface built using **HTML and CSS**.
This project focuses on creating a user-friendly form while practicing accessibility principles, form styling, and CSS layouts.

This project is based on the [Accessible Form UI](https://roadmap.sh/projects/accessible-form-ui) challenge from roadmap.sh.

## Features
- **Form Fields:** Includes full name, email, password, and confirm password inputs.
- **Password Visibility Control:** Displays a button for toggling password visibility.
- **Profile Completeness:** Displays a progress indicator showing form completion.
- **Requirements Checklist:** Shows the requirements needed to complete the profile.
- **Accessible Labels:** Uses properly associated labels for form inputs.
- **Focus States:** Provides visible focus indicators for keyboard navigation.
- **Error Messages:** Includes space for validation feedback.
- **Static Interface:** Focuses on accessibility and visual design without JavaScript functionality.

## Technologies Used
- HTML5
- CSS3

## Learning Objectives
- Practice creating accessible forms using semantic HTML.
- Learn how to associate labels with form inputs.
- Understand accessibility attributes such as `aria-required` and `aria-invalid`.
- Improve keyboard navigation through visible focus states.
- Practice styling form fields, buttons, and progress indicators.
- Learn the importance of readable color contrast and error feedback\
